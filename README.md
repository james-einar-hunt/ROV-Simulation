**Overall Goal:**\
The goal for this project is to develop a forward simulation of a fully-actuated remotely operated vehicle (ROV). The source code for the simulation is written in Python. The simulation runs as a loop which acquires a set of control inputs, evaluates the kinematics and dynamics based on the vehicle state and control inputs, then integrates to take a step forward and repeats the cycle until the simulation ends. The dynamics for the ROV are based on the commonly-accepted, second-order, finite-dimensional dynamical model of an underwater vehicle (which is explicitly defined in this document). Note that the dynamical model itself is agnostic to the type of controller used. This will allow the simulation user to employ different types of controllers (e.g. user-provided open-loop control inputs from a gaming controller, preprogrammed open-loop control inputs, closed-loop PID control, etc.) based on their needs.
